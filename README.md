# SWE40006 Task 3 – Azure Deployment

Source code for Deployment Portfolio Task 3 for **SWE40006 Software Deployment and Evolution**.

## C# Web Application

The C# web application was developed using ASP.NET Core Razor Pages in Visual Studio and deployed to Microsoft Azure App Service.

Source files:

* `CSharp/Pages/Index.cshtml`
* `CSharp/Program.cs`
* `CSharp/AzureCSharpWebApp.csproj`

The C# application was successfully deployed, verified through its public Azure URL, and subsequently stopped to satisfy the Task 3.2 deactivation requirement.

## PHP Web Application

The PHP web application was developed using PHP and deployed to Microsoft Azure App Service using the Linux PHP runtime.

Source file:

* `PHP/index.php`

The PHP application was successfully deployed and remains available through its public Azure URL for verification.

## Deployment Platform

Both applications were deployed using **Microsoft Azure App Service**.

This repository provides the source code for verification. The deployed application URLs are provided in the SWE40006 Deployment Portfolio Task 3 report.
